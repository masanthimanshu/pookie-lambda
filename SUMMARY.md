# Pookie Data Service

Serverless backend for ingesting and storing device telemetry with AWS Lambda, DynamoDB, and Express, delivering a scalable, pay-per-use foundation for connected-system data workflows.

- Built a modular Node.js and Express API architecture with separate read/write services, shared validation, structured logging, and reusable persistence logic for maintainability and faster iteration.

- Deployed infrastructure as code with Serverless Framework to provision AWS Lambda functions, HTTP API routing, and DynamoDB resources with low operational overhead.

- Implemented request validation, health-check endpoints, and resilient error handling to strengthen API reliability, improve input quality, and simplify backend monitoring.

- Delivered a secure, extensible backend foundation for telemetry ingestion and future query-driven read capabilities, supporting scalability and long-term growth.
